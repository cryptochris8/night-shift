# NIGHT SHIFT

One hospital night. Three people. The same three hours.

NIGHT SHIFT is a browser-based psychological horror / mystery prototype. You are not one protagonist: you move between **John** (a patient waiting to be seen), **Susie** (a nurse called in to cover), **Paul** (environmental services, who knows the building better than anyone) and the wing's **CCTV** feeds, while a single shared timeline runs from 10:45 PM to 1:45 AM. What one of them sees, another may not. The cameras may disagree with both.

Everything you see and hear is generated by code at runtime: no imported models, images, fonts or audio files. Geometry is three.js primitives, textures are drawn on canvases, sound is synthesised with the Web Audio API.

## Run it

```bash
npm install
npm run dev        # http://127.0.0.1:5173
```

Production build and preview:

```bash
npm run build
npm run preview    # http://127.0.0.1:4173
```

Requires a modern desktop browser with WebGL 2 (Chrome, Edge, Firefox). Headphones recommended. Contains flickering light.

Touch devices get an on-screen stick and buttons.

## Night Seed

Every shift is generated from a **Night Seed** (shown on the title and ending screens, e.g. `NS-7F3A-21`). The seed decides which anomalies happen, where the clues are, how each character perceives shared events, and what the hospital is actually hiding that night. Enter a seed on the title screen to replay a specific night. The game never tells you which kind of night you got.

## Settings

Master / music / effects volume, motion effects, film grain, reduced flicker, subtitles, mouse sensitivity, invert Y, quality, and **Difficulty** (Easy / Normal / Hard — scales how fast characters get into trouble while you are not watching them).

## Development

```bash
npm run typecheck  # tsc --noEmit
npm test           # vitest (pure logic: rng, clock, state, layout, nav, collision)
npm run smoke      # headless Chromium run through title → play → outage → ending, screenshots in tools/shots
```

Architecture: `src/core` (types, contracts, store/bus, clock, seeded RNG, input) · `src/world` (floor plan, procedural geometry and props) · `src/render` (textures, lighting, post-processing, cinematics) · `src/characters` (first-person controller, procedural figures, navigation) · `src/audio` (synthesised ambience and effects) · `src/cctv` · `src/interact` · `src/ui` · `src/events` + `src/story` (the director: shared timeline, anomalies, perception, choices, endings). `CONTRACT.md` documents the module boundaries and the story spine.

Debug hooks are exposed on `window.__NS` (`setTime(minutes)`, `switchView(view)`, `fire(eventId)`, `state()`); add `#debug=1` to the URL for the overlay.
