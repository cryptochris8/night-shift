# NIGHT SHIFT — Build Contract

Read this before touching any file. It is the agreement that lets many modules be built in parallel and still fit together.

## 0. Non-negotiables

- **Playable, atmospheric, creepy.** Grounded cinematic realism made entirely from code. No imported 3D models, images, fonts or audio files. Everything procedural (three.js primitives, canvas-generated textures, SVG, CSS, Web Audio synthesis). One exception, at the owner's request: the title briefing's narration (`src/assets/briefing.mp3`, recorded with ElevenLabs by `tools/narration.mjs`). It is the only file the game loads besides its code.
- **Stack:** Vite 7 + TypeScript 5 (strict) + three r186. Vanilla DOM for UI (no React). No other runtime dependencies.
- **Priority order for every decision:** atmosphere → immersion → visual realism → psychological tension → gameplay clarity → replayability → performance → elegance.
- **Modules talk only through `src/core/contracts.ts` interfaces + the `EventBus`.** Never import another module's *class*. Import `Services` and use `services.lighting`, `services.audio`, etc. Shared data (`layout`, `types`, `rng`, `clock`, `state`) is in `src/core` and `src/world/layout.ts`.
- **Do not edit files you do not own** (table below). If you need a new shared type, define and export it from your own module. If you believe a contract must change, implement to the contract anyway and note the proposed change in your final report.
- You MAY read every file in the repo. You MUST read `src/core/types.ts`, `src/core/contracts.ts`, `src/core/state.ts`, `src/world/layout.ts`, and `src/main.ts` before coding.
- Code must type-check under `tsc --noEmit -p tsconfig.json` (strict). Run it before you finish; fix every error in your own files. Do not fix other modules' files — report them.
- Keep bundle lean: import from `three` and `three/addons/...` only.
- No `TODO`, no placeholder stubs, no "future work" comments. Every method in your interface does the real thing.
- Comments: brief, explain *why*. No narration.

## 1. Coordinate system & scale

- Metres. `x` east, `z` north, `y` up. Main corridor along `z = 0`, `x ∈ [-20, 20]`, width 2.8 m, ceiling 2.8 m.
- Eye height 1.65 m. Walk 1.5 m/s, "run" 2.4 m/s (slow on purpose).
- Yaw convention (three.js): `yaw = 0` looks toward **−z**; forward = `(-sin(yaw), -cos(yaw))`. Use `forwardFromYaw` from layout.
- Rooms are INTERIOR bounds; the 0.2 m gap between adjacent rooms is the wall. Doors sit in that gap (`DoorDef.pos` is the centre of the gap).
- Wall construction: **single-sided inward-facing planes per room** (no slabs → no z-fighting). Door/window holes are cut by splitting wall planes; door *frames* (jambs) fill the 0.2 m thickness. Set `material.shadowSide = THREE.DoubleSide` so single-sided walls still cast shadows.

## 3. Lifecycle

`constructor()` (no args) → `init(services)` (may be async; store `this.s = services`) → `update(dt, gdt)` every frame → `dispose()`.
- `dt` real seconds (≤ 0.1). `gdt` game minutes elapsed this frame (0 when paused/menus/cinematic).
- The world is built once in `WorldBuilder.init()` via `build()`; `build()` may be called again by `newGame()` and must reset doors/props/decals to the layout defaults (dispose the previous geometry).
- Game time: `services.clock.time` (minutes since 22:45). `formatClock12/24` in `core/clock.ts`. Shift = 180 min = 30 real minutes at the default scale.
- Phases: `PHASE_STARTS` in `core/types.ts`. `store.setPhase` is called by main; listen to `bus.on('phase:change')`.
- Bus events: see `BusEvents` in `core/state.ts`. Emit the ones your module owns (world → `door:changed`; characters → `character:entered`; etc).

## 4. Module specifications

### 4B. World (`src/world/WorldBuilder.ts`, `src/world/props.ts`, `src/world/decals.ts`)
- Build every room from `layout.rooms`: floor (MeshStandardMaterial, vinyl roughness ≈ 0.28 / metalness 0.05 so fluorescent reflections streak; concrete rougher), ceiling (panel grid; service areas = bare concrete slab with `ceiling_pipes` props), four inward-facing walls with door/window cutouts and a baseboard strip. `sides[...].kind === 'glass'` → transparent glass pane (MeshPhysicalMaterial, transmission off, opacity 0.18, slight green tint) with aluminium mullions.
- Doors: real door leaf meshes per `DoorKind` that **animate** (swing 90°, sliding glass slides, elevator splits, counter gate swings). Frame/jamb fills the wall gap. Push-plates, kick plates, small window per `window`. Door label sign above/next to the door via `signTexture`. Badge readers are props (glow dot: green idle, red deny — set via `setScreen(propId,'deny'|'idle'|'ok')`).
- `getObstacles()` returns solid prop footprints (rotated → AABB) **plus** closed-door passages. Walls themselves are handled by the character system from room bounds + door passages — do not return walls.
- `roomAt(p)` → `layout` helper.
- Props (`props.ts`): one builder per `PropType` in `types.ts` — all of them. Realistic proportions, subdued materials, bevelled/multi-part silhouettes (a bed = frame + mattress + rails + pillow + folded blanket, not one box). Monitors/terminals/TV have emissive screens using `screenTexture`; `setScreen(propId, mode)` swaps them. Vending machines glow (emissive front). Curtains: vertical pleated planes on a rail with `params.open`. `chair_row` builds N linked waiting-room chairs. `ambulance`: convincing box-van silhouette with light bar, open rear doors, interior glow. `canopy`: steel columns + soffit with downlights. Generator: skid, engine block, radiator, exhaust, control panel with LEDs, yellow cage. Breaker panels: grey steel with a door and rows of breakers. `plastic_sheeting`: translucent hanging sheets. `puddle`: glossy dark decal plane. `maintenance_tag`: small card on a wire.
- Call lights: `setCallLight(room,on)` lights the dome above the exam door AND the matching lamp on the nurse-station call board.
- Elevator: cab interior, `setElevator(open, lit)` animates doors and toggles the cab light.
- Decals (`decals.ts`): `addFloorDecal` lays alpha-blended planes 2 mm above the floor along `points`, with `fadeAfter` seconds.
- Rain: `setRain(i)` controls a `THREE.Points` streak field over the exterior room only (≤ 4000 points, soft additive). Haze: `setRoomHaze` adds a dim fog plane/low-alpha volume in the room.
- Exterior: asphalt lot, kerb, canopy, sign on the façade above the doors, sky dome (large inverted sphere with `skyTexture`), distant low buildings as dark boxes with a few lit windows, a chain-link fence silhouette. The hospital façade seen from outside is dark brick/concrete panels.
- `moveProp` updates `getObstacles()`.
- Performance: merge static geometry per room where materials match (`BufferGeometryUtils.mergeGeometries`) so the whole wing is a few hundred draw calls; keep interactable/movable props as separate objects. Name objects (`object.name = propId`) and set `userData.room`.
- Emit `door:changed` on open/lock changes. Play `door_open`/`door_close`/`door_locked`/`badge_ok`/`badge_deny` via `services.audio` positioned at the door.

### 4C. Lighting (`src/render/Lighting.ts`)
- Owns `scene.fog` (FogExp2), `scene.environment` (PMREM of `three/addons/environments/RoomEnvironment.js`, intensity ≈ 0.25 normal / 0.08 generator / 0 blackout via `scene.environmentIntensity`), hemispheric ambient, and all fixture lights.
- **Light pool:** a fixed pool of 14 `PointLight` + 2 `SpotLight` (flashlight + one dramatic key) always in the scene (so shader programs never recompile). Each frame, assign pool lights to the nearest/most relevant *energised* fixtures around the active camera (weighted by distance and whether the fixture's room is the camera's room or adjacent). Fixtures beyond the pool get only their emissive geometry. Two pool lights may cast shadows (nearest ones); others don't.
- Fixture visuals: each fixture gets an emissive mesh (troffer panel with `fluorescentPanelTexture`, bare tube strip, exit sign with red glow halo, twin-head emergency unit, sodium lamp cone, desk strip). Emissive intensity follows the mode. Bloom in PostFX picks these up.
- Modes: `on` (steady with 1–2 % imperceptible flutter), `flicker` (irregular, fluorescent-like: ballast buzz pattern, brief drops, not strobing; obey `settings.reducedFlicker` → gentler), `dim`, `dying` (slow fade with sputters), `off`.
- Colour temperatures: normal fluorescent ≈ 0xdfe9ff cool 4100K-ish with slight green; lounge warm 0xffe6c8; emergency heads 0xfff0d6 very harsh and directional; sodium 0xffa040; exit red 0xff3b2a; monitor glow 0x8fd0ff / vitals green 0x6cff9a.
- Power states: `normal` → all main + emergency fixtures on (emergency heads are actually OFF in normal power — they only light on generator), `unstable` → random brownouts/flicker across rooms (`flickerProne` first), `blackout` → everything off except exit signs (battery) and monitor glows die too (`setGlow` off), fog darkens, `generator` → only `circuit === 'emergency'` fixtures whose `zone` is energised in `store.zones`, harsh and sparse; main troffers stay dark. `setZone` reflects Paul's panel; `west_wing` zone powers nothing visible except a glow behind the closed-wing door.
- Flashlight: `SpotLight` parented to the active camera (slight offset right/down, angle 0.42 rad, penumbra 0.5, warm 0xfff2d0, small irregular hand jitter when moving, casts shadows). Only valid when a character has it (main toggles).
- `brightnessAt(p)` = cheap estimate from energised fixtures within range.
- `cascadeOff(room, toward, step)` switches fixtures off one by one, nearest-first → farthest, toward the point.
- `setDawn(a)` lerps background/fog toward a cold blue-grey dawn and raises the exterior ambient.
- Blackout ramps: `setPowerState('blackout')` must be dramatic: a 0.3 s stutter, then everything dies over ~0.5 s. `generator`: 2 s of darkness, then fixtures snap on one zone at a time with 0.3 s gaps.

### 4D. PostFX + Cinematic (`src/render/PostFX.ts`, `src/render/shaders.ts`, `src/render/Cinematic.ts`)
- Pipeline: `EffectComposer` → `RenderPass` → `UnrealBloomPass` (threshold 0.85, strength 0.55, radius 0.4) → custom `ShaderPass` (one fullscreen shader) → `OutputPass`. Quality tiers: `low` disables bloom and halves resolution, `medium` reduces bloom resolution.
- Custom shader uniforms: `uTime, uGrain, uVignette, uChroma (aberration), uBlur (medication; radial soft blur via 8 taps), uTunnel (tunnel vision darkening), uDesat, uWarp (slow low-amplitude breathing distortion when fear high), uBlackout, uHeartbeat (pulse vignette), uMode (0 world / 1 cctv / 2 black), uCCTV params (scanlines, low-res quantisation, colour bleed, noise, timestamp handled by UI), uFlash (transition flashes), uStaticAmt, uFlicker, uTear (horizontal tear offset), uPixelate`.
- `setPerception(p, char)`: target values blended at ~2/s. Mapping: medication → blur 0.6·med + chroma 0.4·med, fatigue → vignette + slight desat, anxiety/stress → grain + subtle warp, fear → heartbeat vignette + tunnel + warp, injury → brief double-vision wobble. Keep it **subtle**: at John's defaults the image is clearly readable.
- `transition(kind, seconds)`: `static` (noise burst with horizontal tear, screen fully noise at mid), `flicker` (fluorescent cut-out: 2–3 black frames + flashes), `cut` (1 black frame), `monitor_on` (black → bright horizontal line → expands with scanline roll), `monitor_off` (reverse), `fade_black`, `fade_in`, `whip` (directional blur). Resolve the promise at the point of maximum obscuration; keep animating the tail.
- `pulse('glitch')` → short tear + chroma spike; `pulse('heartbeat')` → single vignette thump; `pulse('hit')` → flash + shake-like offset.
- Film grain honours `settings.filmGrain` (off → tiny); `motionEffects` off → no warp/wobble.
- `render(scene, camera)` renders through the composer; `resize` updates composer and bloom sizes.
- **Cinematic:** owns its own `PerspectiveCamera`. `play(id, shots)` interpolates pos/lookAt per shot with easing, optional handheld shake (perlin-ish), FOV, per-shot `transition` via `services.postfx.transition`, captions via `services.ui.caption`, locks input (`store.lockInput(true)`, `characters.setMovementEnabled(false)`), hides HUD (`ui.setHudVisible(false)`), shows letterbox bars (CSS class on `uiRoot`: `cinematic`), emits `cinematic:start/end`. Skippable with `skip` action (Space/Enter) when `skippable`. Restores everything on finish.

### 4E. Characters (`src/characters/*`)
- **Player controller:** first-person, pointer-lock mouse look (sensitivity × settings), gamepad right stick look, WASD/left-stick move, run with Shift. Capsule radius 0.3 m. Collision: stay inside the current room's bounds unless passing through a door passage you `canPass`; slide along walls; solid prop AABBs from `world.getObstacles()`. Head bob (subtle, scaled by `setMotionScale`), footstep SFX timed to bob (`footstep_tile` on vinyl/tile, `footstep_concrete` on concrete/asphalt, `footstep_wet` when standing on a puddle decal → check `world`). Stairs: none. Crouch: none.
- Doors: walking into a closed door you can pass auto-opens it (`world.setDoorOpen`), and it closes ~2 s after you leave the passage. Walking into one you cannot pass: door rattles (`door_locked`), badge reader flashes red if `badge` (`world.setScreen(readerId,'deny')`), emit `door:denied`. Badge doors for staff: `badge_ok` chirp. Locked doors (`handle.locked`) deny everyone.
- When John tries a staff door, show the deny; the UI prompt system (G) shows "Staff only" via `services.ui.setPrompt` briefly.
- Update `store.setChar(id, { position, yaw, location })` each frame for the controlled character and NPCs (location via `world.roomAt`).
- **NPC bodies for the 3 main characters:** when not possessed, each has a `Figure` that follows its **schedule** (`setSchedule`) — walk along the waypoint graph (`nav.ts`: A* over `layout.waypoints` + straight-line final approach) to the entry whose time has passed, then perform `action` (sit/stand/work/mop/phone/lie). Walk speed 1.3 m/s. They open doors they can pass (`world.setDoorOpen`) and never pass doors they cannot. If the player releases control somewhere else, the NPC resumes from there.
- **Figure (`Figure.ts`): procedural humanoid from primitives** — realistic proportions (total 1.72 m, head 0.23 m, shoulders 0.42 m), capsule torso, cylinder limbs with elbow/knee joints, a sculpted head (`Figure.head.ts`), hands/feet as small boxes. Outfits by colour/material: scrubs (teal 0x3f7f86 top + trousers), patient (pale gown 0xbfd2d6 + bare forearms), workwear (navy 0x2d3a5c + grey shirt + key ring), security (black 0x15171c + white shirt collar), clerk (burgundy cardigan), coat (white coat), dark (matte 0x0b0b0d, no highlights, slightly taller 1.9 m, arms a touch too long), child (1.1 m), paramedic (navy with reflective stripes). Each head is one sculpted surface per face preset (`Figure.head.ts`: blended signed-distance shapes for the cranium, jaw, cheekbones, brow, nose, lips, chin and ears), sampled once at load and painted per figure in vertex colours over the skin colour 0x9d7b66 (`roughness 0.9`): hair, brows, lips and baked cavity shading. The eyes stay soft shadowed hollows; nothing is drawn on. Presets vary by seed, Susie's scrubs (and `FigureOptions.face: 'soft'`) get the softer face with a bun, and the dark figure stays faceless. Animations are procedural: walk cycle (legs/arms swing, slight bob, head stable), limp (asymmetric cycle), wrong_gait (period irregular, knees bend too late — subtle), slow (0.4× cycle, 0.5× speed), drag (one leg trailing), idle (breathing 0.6 Hz, weight shifts every 3–6 s), sit (on chair/bed height 0.45), lie (on bed 0.6), work (hands at counter height, small movements), mop (sway), phone (head down, hand up, faint screen glow emissive on face), glitch (random 1–2 frame pose jumps, only when `visibleTo` includes 'cctv' and viewing CCTV), stand_still (completely motionless — no breathing — this is unsettling; use for anomalies).
- `visibleTo`: set `object.visible` according to the current view filter (`setViewFilter`); CCTV calls `setViewFilter('cctv')` before rendering its feed and back afterwards.
- `canSee(target, fov, maxDist)`: in frustum cone and no wall between (ray against room bounds: same room or line passes through an open door passage).
- `isSeen()` on figures uses `canSee` on the figure's chest.
- Danger/missing have no visuals here (director handles).
- Disable the possessed character's own body (hide) but keep a subtle shadow blob under the camera? No — just hide.
- Camera: `fov 70`, near 0.05, far 120. Attach a `THREE.AudioListener`? No — audio engine takes `setListener(pos,yaw)` each frame from you.
- Emit `character:entered` when `location` changes.

### 4F. Audio (`src/audio/*`)
- Pure Web Audio synthesis. Graph: master gain → compressor → destination. Buses: `ambience`, `sfx`, `music`, `ui`, with `ConvolverNode` reverb per room class (generated impulse responses: small tiled room, corridor long, concrete service hall, outdoors with rain). Ducking gain node before master.
- **Ambience layers** (looping synthesized sources, crossfaded by `setSoundState` + `setRoom` + `setPowerState`): HVAC rumble (brown noise lowpass 120 Hz + slow LFO), fluorescent/ballast hum (60 Hz + 120 Hz + 180 Hz sines, faint, with per-room detune; off in blackout; harsher 50/100 Hz "generator" hum after), ventilation hiss (pink noise bandpass 1.2 kHz, breathy), distant monitors (sparse soft beeps, random intervals 4–9 s; only in clinical rooms), vending hum (near vending machine), rain (filtered noise with droplets; outdoors loud, through glass muffled, in waiting room faint), far traffic swell, elevator motor whine when moving, generator (low 30 Hz + 60 Hz with mechanical knocks at ~1.5 Hz, louder near generator room).
- **Random event scheduler** per sound state: NORMAL — carts rolling far away, distant door, rubber shoes squeak, muffled voices, cough, elevator tone, intercom click, plumbing knock (interval 8–25 s). UNEASY — fewer ordinary sounds, occasional sound from a *wrong direction* (pan opposite to any room geometry), single footsteps without rhythm, faint knock. PRE_OUTAGE — hum detunes and swells, lights buzz, low 40 Hz drone creeps in, rhythmic click of a failing ballast. BLACKOUT — everything stops; only rain/car alarm far outside, breathing of the active character, a slow heartbeat; silence is the point. GENERATOR — harsh hum, generator thrum through walls, intermittent relay clicks, no monitors, dripping. THREAT — sub drone 32–45 Hz with slow beating, distant dragging, something in the vents (filtered scrapes), heartbeat follows `setHeartbeat`, sudden total silences (`silence`) for 2–4 s. RESOLUTION — thin, cold, almost nothing; a distant bird? No birds: a single sustained high sine, slow rain fade.
- `play(name)`: every `SfxName` in contracts is a synthesized one-shot (footsteps: filtered noise bursts with heel/toe two-tap; doors: low thump + hinge sweep; monitor beep: 880 Hz short sine; intercom click: filtered pop + hum; elevator tone: two-note chime; vending drop: thud + rattle; phone buzz: 160 Hz square pulses; static burst: white noise envelope; whisper: breath noise with formant filters; name_call: formant vowel sequence at ~2 kHz tilt (unintelligible but voice-like); child_laugh: short descending chirps with noise; drag: long filtered noise with grit; etc). Spatial: `PannerNode` HRTF for positioned sounds (`pos` relative to `setListener`), distance rolloff inverse, ref 1.5 m; `nonSpatial` → straight to bus.
- `intercom(text)`: uses `speechSynthesis` if available — pick a low-rate (0.92) voice, pitch 0.9 — and simultaneously plays an intercom click, hum bed and a bandpassed noise layer; since speech can't be routed through Web Audio, lower the master slightly while it speaks for a "PA" feel. Fallback: `murmur`. Resolve when `onend` or after an estimate.
- `setPerception`: John's medication → lowpass sweep (cutoff 20 kHz→4 kHz at med 1) + 3 cents detune on ambience; fear → heartbeat + highpass thinning of ambience + louder breath; fatigue → slower, duller; CCTV mode → bandpass 300–3400 Hz, mono, light compression + camera hum.
- `applySettings`: master/music/sfx gains.
- `narrate(url)` / `stopNarration(fade)` / `narrationStatus()`: the recorded title briefing (`narration.ts`). It is a plain media element beside the graph rather than a node in it, so it can start in the gesture that asks for it, before `unlock()`. Its volume follows the master curve. While it plays, the menu duck drops the world from 0.35 to 0.14 under the voice. Stopping fades it per frame, with a wall-clock backstop for when frames stall. `game:new` fades it out.
- Must not start the context before `unlock()`. All methods are safe no-ops before unlock, except the narration, which never touches the context.

### 4G. Interaction (`src/interact/InteractionSystem.ts`)
- Each frame (when a character is possessed, not locked, no modal): raycast from the camera centre against registered `Interactable.object`s (recursive) within `radius` (default 2.2 m); `loose` ones also qualify if within radius and within 35° of centre. Pick the closest. Call `services.ui.setPrompt(prompt(c))` ("E — Open chart" formatting is UI's job: pass plain "Open chart"). `trigger()` awaits `use(c)` with a 0.25 s cooldown and emits `interact:used`.
- Gamepad/touch friendly: no mouse clicks needed.
- Highlight: a faint emissive pulse on the targeted object (store original emissive, restore on untarget). Keep it subtle.

### 4H. CCTV (`src/cctv/CCTVSystem.ts`)
- One `PerspectiveCamera` per `layout.cameras` (aspect 4:3 feel: render full-frame but let the shader pillarbox/vignette). `renderFrame()`: set `characters.setViewFilter('cctv')`, run injections, call `services.postfx.render(scene, cam)`, then restore the previous filter. Before rendering set `postfx.setCCTVParams({degradation, online, label, timestamp: formatClock24(time)})` and `ui.setCCTVOverlay({...})`.
- Offline cameras: render nothing (postfx shows "NO SIGNAL" static; set `online:false`). `survivesBlackout === false` → offline from blackout onward; `zone` not energised on generator → offline. React to `bus.on('power:change')` and `'zone:change'`.
- Degradation grows with phase (listen `phase:change`): 0.1 normal, 0.25 unease, 0.4 contradictions, 0.7 generator+, 0.85 crisis. Effects via `setCCTVParams`; also schedule random `glitch` of your own (skip frames: hold the previous frame for 2–6 frames; `timestamp` glitch: UI overlay shows a jumped time for a few frames — expose via `setCCTVParams.timestamp`; `rollback`: feed shows the frame from ~2 s ago — keep a tiny ring buffer of 1 render target at low res to re-blit, or fake with a freeze + jitter).
- `inject(cameraId, frames, setup)`: for the next N rendered frames of that camera, call `setup(scene)` before rendering and its returned cleanup after. Used for the "two frames of a figure" moments.
- `enter()` picks `cameraId`, else last used, else the first online; `next/prev` cycle only online+offline (offline shows NO SIGNAL so the player learns which went down). Play `cctv_switch` on change.
- `markFootage` stores `{cameraId,label,time}` and adds a `Clue` (`kind:'footage'`, `supports:'ambiguous'`) via `store.addClue`.
- Audio: on enter, `services.audio.setCCTVMode(true)` is done by main; you set the listener to the camera pose each frame while active.

## 6. Visual direction (everyone)
Dim, cold, clinical; subdued desaturated materials; glossy vinyl floors with long fluorescent reflections; subtle grime at corners/baseboards; realistic proportions; soft shadows; fog slight. Generator night: harsh pools of warm-white light from emergency heads, deep shadows between, red exit signs, amber generator glow in service areas. Never full black: the player can always read silhouettes. Horror through incomplete visibility: doorways, curtains, glass, distance, reflections, two frames of footage. **Subtlety is scarier. Never strobe.**

## 7. Audio direction (everyone)
Audio carries the horror. Baseline hospital bed is dense but quiet; escalation is mostly subtraction plus wrongness (direction, rhythm, silence). No constant loud jump scares. One or two stings max per run, earned.
